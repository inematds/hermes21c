🐕 O que é o Hermes (e quando usar)

Onde o Hermes se encaixa frente a Claude Code, OpenClaw e IDEs. A ideia que organiza tudo: o Hermes é seu cão, não o contratado — mora com você, te conhece e melhora ano a ano.

1

🐕 Hermes = seu Labrador

A analogia central: o Hermes é como seu cão. Ele mora com você, te conhece e fica melhor ano após ano. Não é uma ferramenta que você liga e desliga: é uma relação de longo prazo.

🏡 O que "morar com você" significa

  • •Persistência: não esquece quem você é entre conversas
  • •Familiaridade: aprende seu jeito, suas rotinas, seus projetos
  • •Evolução: cada mês fica mais útil, não menos

💡 Dica prática

Trate o Hermes como um companheiro de longo prazo: invista nele no início (memória, soul, integrações) e o retorno cresce com o tempo.

2

👷 Claude Code = o contratado

O Claude Code é o contratado: excelente para um job específico, uma ferramenta de precisão. Mas ele não mora com você nem te lembra na próxima vez.

✓ O contratado é ótimo para

  • ✓Um trabalho técnico de precisão (código)
  • ✓Tarefas pontuais com começo, meio e fim
  • ✓Profundidade num projeto específico

✗ O contratado NÃO faz

  • ✗Lembrar de você na próxima sessão
  • ✗Acompanhar você no dia a dia
  • ✗Construir uma relação de longo prazo

Importante: não é "melhor ou pior" — são papéis diferentes. O módulo 3.7 mostra como conectar os dois para que compartilhem memória.

3

🛋️ OpenClaw & anti-gravity

Para completar o mapa: o OpenClaw é o colega de quarto e o anti-gravity é sua IDE/parceiro de código. Cada peça do ecossistema cumpre um papel.

🐕

Hermes — seu cão

Mora com você, te conhece, melhora com o tempo. Companheiro persistente.

👷

Claude Code — o contratado

Ferramenta de precisão para um job; não te lembra depois.

🛋️

OpenClaw — colega de quarto

Divide o espaço com você no fluxo de trabalho.

🧑‍💻

anti-gravity — sua IDE/parceiro

O ambiente onde você programa lado a lado com a IA.

4

📈 Quanto mais você usa, mais te conhece

A essência do Hermes: quanto mais você usa, mais ele te conhece — e mais útil fica. O valor é composto: cresce com o tempo, não aparece de uma vez no primeiro dia.

📊 Efeito de acúmulo

  • •Dia 1 — um agente genérico, capaz mas que não te conhece
  • •Semanas depois — sabe seus projetos, contatos e preferências
  • •Meses depois — antecipa o que você precisa antes de pedir

💡 Dica prática

Não julgue o Hermes pelo primeiro uso. O ganho real aparece quando ele já acumulou contexto sobre você — a memória (Trilha 2) é o motor disso.

5

🏃 Quando usar Hermes (e quando não)

Regra simples: use o Hermes quando estiver móvel — café, academia, no celular. Use ferramentas de desktop quando estiver na mesa, com foco e teclado.

✓ Prefira o Hermes

  • ✓Longe da mesa (café, academia, rua)
  • ✓Pelo celular, em movimento
  • ✓Tarefas que dependem do seu contexto pessoal

✗ Prefira desktop tools

  • ✗Sessão longa de código na mesa
  • ✗Quando precisa de IDE e teclado
  • ✗Trabalho de precisão num projeto técnico
6

🎨 Design ethos: viver com você

O princípio de design do Hermes é viver com você e melhorar com o tempo — não ser uma ferramenta descartável. Esse ethos explica praticamente todas as outras decisões do produto.

🧬 O ethos em decisões concretas

  • •Memória local (Trilha 2) — para acumular contexto sobre você
  • •Soul.md — para ter a sua personalidade e o seu jeito
  • •Backup no GitHub (Trilha 3) — para nunca perder a relação construída

💡 Dica prática

Sempre que uma decisão do Hermes parecer estranha, pergunte: "isso ajuda ele a viver comigo e melhorar?" — normalmente a resposta explica o porquê.

7

🧯 Erros comuns & o mapa de bolso

Antes de fechar: os tropeços mais frequentes de quem começa — e uma referência rápida de qual ferramenta usar para cada situação.

✓ Faça

  • ✓Dê tempo: o valor cresce com o uso
  • ✓Invista cedo em memória e soul
  • ✓Escolha a ferramenta pelo contexto (móvel x mesa)

✗ Evite

  • ✗Esperar "mágica" no primeiro dia
  • ✗Esperar que o Claude Code te lembre depois
  • ✗Usar o Hermes para o que pede IDE e teclado

Mapa de bolso (qual ferramenta usar)

móvel / acompanha você / contexto pessoal  -> 🐕 Hermes
job técnico de precisão / sessão única      -> 👷 Claude Code
colega no fluxo de trabalho                 -> 🛋️ OpenClaw
ambiente de código lado a lado              -> 🧑‍💻 anti-gravity (IDE)
