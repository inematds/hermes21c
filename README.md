# Hermes 21C — Todos os Conceitos do Hermes

Os **21 conceitos do Hermes** (o agente de IA), do mais simples ao mais poderoso, explicados para pessoas comuns — com exemplos práticos e diagramas SVG.

🔗 **Página:** https://inematds.github.io/hermes21c/

## O que é

Curso didático em HTML estático (Tailwind via CDN, dark/light mode, sem build) que destrincha os 21 conceitos fundamentais do agente Hermes: de "agente, não chatbot" até conectar tudo num *operating system* com o Claude Code.

## Estrutura

3 trilhas · 21 módulos · ~7 horas.

| Trilha | Cor | Conceitos |
|--------|-----|-----------|
| 🌱 **T1 — Fundamentos** | Emerald | 1. Agente, não chatbot · 2. O que é o Hermes · 3. Um cérebro, 22 bocas · 4. Onde o Hermes vive · 5. OAuth vs API key · 6. Escolhendo o modelo · 7. Local & privado |
| 🧩 **T2 — Capacidades** | Blue | 8. Memória · 9. Soul.md · 10. Integrações · 11. Ações no computador · 12. MCPs · 13. Skills & muscle memory · 14. 6 teclas de poder |
| 🚀 **T3 — Poder & Operação** | Purple | 15. Segurança · 16. Northstar (goals) · 17. Sub-agentes · 18. Heartbeat/cron · 19. Budget & tokens · 20. Operating System · 21. One brain (Hermes + Claude Code) |

## Como rodar localmente

```bash
python3 -m http.server 8000
# abra http://localhost:8000
```

Material **didático e educacional**, não oficial. Hermes é um agente de IA self-hosted de terceiros; comandos como `/model`, `/queue`, `/background`, `/compress`, `/goal` são ilustrativos do fluxo descrito.
