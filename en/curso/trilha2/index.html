🧠 Memory

Hermes remembers what you tell it. MEMORY.md + full-text search and recall of everything: it never starts from scratch.

What is:

A simple text file (markdown) that stores what matters about you — facts, preferences, context.

Why learn:

It's human-readable and lives on your machine; you can open and edit it whenever you want.

Key concepts:

Plain text; transparent; portable.

What is:

An index that lets you search any message from any session by word or date.

Why learn:

You recover “what I asked on May 19” without relying on human memory.

Key concepts:

Full recall; search by date; complements MEMORY.md.

What is:

Memory builds up in the background while you use it.

Why learn:

It takes ~2 weeks of use for the agent to become truly useful—patience pays off.

Key concepts:

Compounding effect; the more you use it, the better it gets.

What is:

Connecting external sources (Obsidian, Pinecone, Claude Code memory, PC apps) expands what Hermes knows.

Why learn:

More sources = more accurate, proactive advice.

Key concepts:

Expanded memory; knowledge integrations.

What is:

During idle periods, the agent processes what it has learned and proactively comes back with ideas.

Why learn:

Turns passive memory into initiative: it suggests things before you ask.

Key concepts:

Idle processing; proactivity.

What is:

Without knowing what you do, it can't give precise advice. Memory is the foundation of everything.

Why learn:

Defines the philosophy: a useful agent is one that knows you.

Key concepts:

Context = quality; everything system.

📜 Soul.md

The file that gives Hermes its personality. It's what makes YOUR agent different from all the others.

What is:

A file that turns a generic chatbot into an assistant with YOUR vibe.

Why learn:

Without a soul, the agent doesn't know who to be.

Key concepts:

Identity; personality defined in text.

What is:

Defines the agent’s identity, mission, goals, and values.

Why learn:

Provides direction: the agent knows what to prioritize.

Key concepts:

Mission; values; goals.

What is:

Sets the tone: it can say “bro,” “dude,” be formal, or be direct.

Why learn:

The conversation feels natural and works your way.

Key concepts:

Tone; form of address; voice.

What is:

You can give the agent a character archetype.

Why learn:

A consistent character is more pleasant to use.

Key concepts:

Archetype; consistency.

What is:

The soul is what makes your Hermes different from everyone else's.

Why learn:

Real customization, not the same chatbot as everyone else.

Key concepts:

Uniqueness; customization.

What is:

There’s a template with identity, mission, goals, and business details to fill in.

Why learn:

You don’t start from a blank page.

Key concepts:

Template; guided completion.

🧰 Integrations

Hermes comes with several integrations; you just provide the API key—and NEVER in chat. It connects your whole world.

What is:

Hermes comes with ready-to-use integrations: text-to-speech, image generation, vision, web search.

Why learn:

You enable capabilities without writing any code.

Key concepts:

TTS; image; vision; web.

What is:

Each integration only needs the service's key to work.

Why learn:

Simple setup, but the key needs to be stored securely.

Key concepts:

One key per tool.

What is:

Everything you type in the chat is saved/indexed — a pasted key becomes a permanent risk.

Why learn:

A leaked key can cost you a lot. Golden rule.

Key concepts:

Chat = logged; key stays out of chat.

What is:

Ask Hermes for a terminal command, replace the placeholder with your key, and paste it into the terminal.

Why learn:

The key stays outside the chat history, in the system environment.

Key concepts:

env var; placeholder; terminal.

What is:

Granola integration: "what was the last meeting and 1 action item I promised?".

Why learn:

Shows an integration solving a real everyday problem.

Key concepts:

Meetings; promised actions.

What is:

Tools like Granola MCP use OAuth: just provide the MCP name and authorize it in the browser.

Why learn:

No keys to manage; connect by logging in.

Key concepts:

OAuth; authorization in the browser.

🔌 MCPs

Model Context Protocol: the instruction manual that connects Hermes to practically everything, in a token-efficient way.

What is:

A pattern that packages a tool for the model to use — the manual wrapped around the API.

Why learn:

It's how Hermes connects to almost everything in a standardized way.

Key concepts:

Protocol; standardization.

What is:

The API is the exposed wiring; the MCP is the package of instructions around it.

Why learn:

It's a "universal remote control" — an analogy that makes the concept clear.

Key concepts:

Wiring vs. manual; universal control.

What is:

The model reads the manual and already knows all the buttons, without repeated checks.

Why learn:

Uses far fewer tokens and standardizes usage.

Key concepts:

Token efficiency; less overhead.

What is:

Meeting MCP: accesses notes and action items via OAuth authorization.

Why learn:

Simple plug-and-play MCP example.

Key concepts:

Meetings; OAuth.

What is:

Starts servers that connect to apps; you add tools (e.g., read email) and generate a token.

Why learn:

Opens thousands of apps — add the token via env, not in chat.

Key concepts:

Token via env; selective tools.

What is:

Add “read email,” but hold off on “send/reply to email” until you trust the flow.

Why learn:

Least access prevents damage; never put tokens in chat.

Key concepts:

Least privilege; secure token.

🎯 Skills & Muscle Memory

The more you use it, the better it gets. Give feedback, build skills, delegate to the right models.

What is:

The more you use it and give feedback, the more Hermes iterates and improves.

Why learn:

Your usage trains the behavior — muscle memory.

Key concepts:

Feedback; iteration.

What is:

Hermes has skills it gains through use, and you can build your own.

Why learn:

Skills are recorded workflows for how to do tasks.

Key concepts:

Skills; agentskills.io.

What is:

You create personas (e.g., "the Alchemist") with a job, description, system prompt, and their own model.

Why learn:

Dedicated specialists for specific tasks.

Key concepts:

Personas; model per persona.

What is:

Expensive models only for high-impact tasks; autopilot uses a low-cost model.

Why learn:

Saves money without sacrificing quality where it matters.

Key concepts:

Cost-effectiveness; model allocation.

What is:

"Research the best country to live in": spins up a sub-agent, uses DeepSeek V4 + GPT in a loop, with Opus 4.7 reviewing.

Why learn:

Skill that delegates to different models depending on the role.

Key concepts:

Delegation; model loop.

What is:

The command /stop stops the task in progress.

Why learn:

Control: you can stop whenever you need to.

Key concepts:

Interruption; control.

⌨️ 6 Power Keys

Commands that boost how you work—and why the context window changes everything.

What is:

Queues a prompt for the next turn without interrupting the current one.

Why learn:

You move on to the next step while it works.

Key concepts:

Queue; next turn.

What is:

Runs tasks in parallel in the SAME chat — multiple concurrent workflows.

Why learn:

Does more things at once without opening multiple windows.

Key concepts:

Parallelism; concurrency.

What is:

/canban opens a task board; /reset clear everything.

Why learn:

Organizing and starting fresh improves performance.

Key concepts:

Kanban; reset.

What is:

Compresses memory/context: "summarize everything we’ve discussed" and continues with less.

Why learn:

Less context = better performance and lower cost.

Key concepts:

Compression; summary.

What is:

Switch the model that’s thinking — the brain of Hermes.

Why learn:

Uses the best model for each task (see Track 1).

Key concepts:

Model-agnostic; brain switching.

What is:

Each question uses ALL the context + the question; the larger it is, the worse the performance.

Why learn:

Ideal: one session, one window; reset and compact.

Key concepts:

Context; reset; compress.
