💓 Heartbeat / Cron · Works while you sleep

A chatbot only exists when you open the app. An agent with heartbeat is always alive: a periodic heartbeat keeps it awake, recovers stuck tasks, and runs routines on its own—like the 8 a.m. briefing that arrives before you wake up.

💓 What Is a Heartbeat

Heartbeat is a cron job (a recurring task) that keeps the agent awake all the time, instead of just reacting when you speak. It’s literally a heartbeat: at each interval, something "pulses" and checks whether there’s work to do. It’s what turns a reactive chatbot into an agent that operates on its own.

Illustrative diagram · the heartbeat that never stops

2

🧟 Zombie detection

A “zombie process” stays silent until something dies — a task that got stuck but doesn’t alert you. The heartbeat solves this with a sub-agent that ping every few secondsIf a process stops responding, it’s detected, restarted, and the task is retried, including recovering from hallucinations.

🔧 What ping does

  • Zombie detection — finds stuck processes that would otherwise stay stuck forever.
  • Fresh agent reclaim — replaces the dead agent with a new one, with a clean context.
  • Retries with recovery — tries again and corrects course when the agent hallucinated.

💡 Practical tip

This detection network is what makes it safe to leave the agent running without watching it. Without it, a single stuck task would paralyze the entire operation.

3

⏰ Cron / scheduled task

Besides keeping it alive, the heartbeat allows schedule actions at an interval. The material’s minimal example: “remind me in 30 seconds that the sky is blue.” Hermes saves the task and triggers it automatically when the time comes — you don’t even need to have the app open.

Scheduling examples (illustrative)

/cron remind me in 30s that the sky is blue
/cron every day at 8 a.m.: morning briefing
/cron every Friday at 5 p.m.: weekly summary

The use case that makes the feature shine: every day at 8 a.m., Hermes scans email + calendar + everything it knows about you (memory) and delivers 5 relevant itemsIt’s not a raw list — it’s curated. Cron + memory + integrations turn it into a proactive assistant.

⚠️ Scheduling precautions

Heartbeat and crons are powerful, but every trigger uses tokens. Too many scheduled tasks create hidden costs and a flood of notifications. This connects directly to the next module (3.5, Budget): a forgotten cron job can burn money while you sleep.

🚨 Caution

Periodically review active cron jobs. A schedule that runs every minute, multiplied by the ~73% fixed overhead of each request, turns into an unpleasant bill.
