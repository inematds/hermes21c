🤖 Agent, not chatbot

The difference that changes everything. A chatbot explains HOW to do something; an agent DOES it. You give it a goal, it has tools, and it takes real-world actions.

💬 Chatbot vs. Agent: Talks vs. Acts

The difference is simple and radical: one chatbot tells you HOW to book a flight; one agent really backupA chatbot returns text; an agent returns an action completed in the real world.

🎯 The central idea

You no longer need to turn advice into a sequence of clicks. You describe the goal, and the agent goes through the steps on its own:

  • •Chatbot: "To book, go to site X, choose the dates, compare prices, and complete the booking."
  • •Agent: searches, compares, chooses, and gives you the booking (or the option ready to confirm).

✓ The agent delivers

  • ✓A completed action, not a tutorial
  • ✓Several steps executed automatically
  • ✓A ready-to-use result

✗ The pure chatbot

  • ✗Only describes the path
  • ✗You still do all the work manually
  • ✗Don't touch any tool
2

👤 The assistant analogy

Think of a smart friend versus one personal assistantA friend gives great advice; an assistant takes on the task and gets it done. Both are useful, but for different things.

1

Smart friend (chatbot)

You ask; it advises.

"You should compare three websites and check flights with a layover." — good advice, but you’re still doing the work.

2

Personal assistant (agent)

You delegate; it executes.

"I’ve got it." — it compares, picks one, and comes back with the solution ready.

💡 Practical tip

When you catch yourself copying the steps an AI described and carrying them out by hand, that's a sign you wanted an agent — not a chatbot.

3

✈️ The flight example

A concrete example: "find the cheapest flight from Dubai to Toronto in the next 2 weeks"The agent researches, compares options, picks the best one, and opens the result in a polished HTML page for you to decide.

1

You set the goal

A natural-language sentence, without detailing each step.

2

It researches

Scans dates, routes, and prices using web search and a browser.

3

It selects and delivers

Presents the best option in a well-organized HTML page, ready for you to confirm.

Illustrative command

Ache o voo mais barato de Dubai a Toronto nas
próximas 2 semanas e me mostre as 3 melhores opções.

📱 Accessible Wherever You Are

Hermes is an AI with tools that you can access from wherever you are, on your phoneIt’s not an app tied to your desk: it’s an agent that goes with you.

🚶 In the real world

You can kick off a task on your way to work and get the finished result when you arrive. The agent doesn’t require you to be at your computer to work for you.

  • •Trigger it from your phone; receive the result when you return
  • •Works while you do something else

💡 Practical tip

Mobility is exactly where Hermes shines — module 1.2 explains when to prefer it over desktop tools.

6

⚠️ When you DON'T need an agent

Not everything needs an agent. For a quick question, a chatbot can handle it. The agent shines when there's a task with steps to execute.

✓ Use an agent when

  • ✓There’s a multi-step task to complete
  • ✓You need to use tools (email, web, files)
  • ✓You want a result, not a tutorial

✗ Chatbot is enough when

  • ✗It's just a definition or quick explanation
  • ✗There’s nothing to execute in the world
  • ✗You just want to think out loud

Rule of thumb: question = chatbot; task = agent. Using the agent for everything works, but can be overkill (and costly) for trivial questions.

7

🧯 Common mistakes when getting started

People coming from chatbots often make the same mistakes. Knowing about them in advance prevents frustration and helps you get more out of the agent from the start.

1

Asking for advice instead of delegating

"How do I do X?" gets a tutorial. "Do X" gets X done. State the goal, not the step-by-step instructions.

2

Don’t connect any tools

Without tools, the agent becomes a chatbot. Connect at least web and email so it can take action.

3

Use an agent for a trivial question

For a quick definition, a chatbot gets the job done for less. Save the agent for tasks.

From “question” to “task” (illustrative)

# chatbot (fala)
"Como eu comparo preços de voo?"

# agente (faz)
"Compare os voos Dubai→Toronto das próximas 2 semanas
 e me mande as 3 opções mais baratas."
